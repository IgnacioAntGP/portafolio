Instaladas las siguientes bibliotecas:
Bootstrap5 (mediante CDN)
Jquery v4.0.0 (mediante CDN)
11ty - Para manejo de plantillas base y renderizado en vivo del sitio (usar "npm run dev")

Pasos para inicializar:

1. Clonar o Descargar el repositorio (por ahora descarga solamente, aún debo crear el repositorio en GitHub)

2.  Abrir terminal en la carpeta raíz del proyecto e instalar dependencias necesarias: npm install

3. Inicia el servidor de desarrollo local con recarga en vivo: npm run dev

4. Abrir el navegador en la dirección que especifica la terminal, generalmente es http://localhost:8080

Nota. la carpeta que se genera '/dist/' es generada por 11ty, que sería la carpeta de "producción"
