Diseño de Clases & Principios POO

El núcleo del gestor desacopla la captura por consola de la lógica de procesamiento para cumplir con el Principio de Responsabilidad Única (SRP):

  • Herencia y Polimorfismo: Definición de la clase abstracta base Tarea extendida por TareaNormal y TareaUrgente, permitiendo al contenedor GestorTareas manipular listas polimórficas (List<Tarea>).
  • Encapsulamiento: Atributos protegidos y privados gestionados mediante accesores controlados, junto con identificadores gestionados por el método de negocio generarNuevoId().
  • Programación Defensiva: Módulo de utilidades dedicado para el saneamiento de entradas con Scanner, previniendo excepciones por entrada de datos inválida mediante bucles de reintento controlados.

Suite de Pruebas Unitarias - JUnit 5

Estructuración de casos de prueba mediante @BeforeEach:

  • Documentación (@DisplayName): Descripciones semánticas y legibles en cada método de prueba que detallan el requerimiento verificado ante fallos o reportes de compilación.
  • Separación de Clases de Test: Distribución de pruebas (GestorTareasTest, TareaNormalTest, TareaUrgenteTest) validando colecciones, ordenamiento con Comparator y aserciones compuestas (assertTrue, assertEquals, assertFalse).
  • Cobertura de Código: Exclusión de la capa de presentación de consola (.run) en la configuración de EclEmma para medir estrictamente la lógica de negocio, alcanzando más del 88% de cobertura en el código fuente.

Ejecución & Distribución

Empaquetado para ejecución autónoma mediante terminal sin dependencia de un IDE:

Comando de Inicialización

java -jar SmartTask.jar

Requiere un entorno de ejecución Java JRE 17 o superior disponible en la ruta del sistema.
